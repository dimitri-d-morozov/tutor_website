# Формат файла для загрузки теста

Тест загружается в банк одним `.json`-файлом через **Тесты → Загрузить тест**.

Файл удобно готовить с помощью Клода: откройте новый чат, приложите этот документ и напишите,
например: *«Сделай тест на 12 вопросов по теме "Законы Менделя" для ЕГЭ в описанном формате»*.
Полученный файл сохраните как `.json` и загрузите.

Перед сохранением платформа показывает **превью**: название, теги, все вопросы с отмеченными
верными ответами. Пока вы не нажали «Сохранить в банк», в базу ничего не попадает.

## Пример

```json
{
  "title": "Законы Менделя",
  "section": "Генетика",
  "topic": "3.1",
  "levels": ["ege", "olympiad"],
  "time_limit_min": 18,
  "questions": [
    {
      "text": "Какой органоид отвечает за синтез АТФ?",
      "type": "single_choice",
      "options": ["Митохондрия", "Рибосома", "Аппарат Гольджи", "Лизосома"],
      "correct": 1,
      "explanation": "АТФ синтезируется в митохондриях."
    },
    {
      "text": "Сформулируйте первый закон Менделя.",
      "type": "open",
      "answer": "Закон единообразия гибридов первого поколения",
      "explanation": "Проверяется вручную."
    }
  ]
}
```

## Поля теста

| Поле | Обязательно | Что писать |
|---|---|---|
| `title` | да | Название теста, как он будет виден ученику |
| `topic` | **да** | Тема из справочника — код (`3.1`) или название (`Генетика`) |
| `section` | нет | Отдел. Если не указан, берётся отдел темы — обычно это поле не нужно |
| `levels` | да | Уровни: `oge`, `ege`, `olympiad`. Можно несколько |
| `time_limit_min` | нет | Лимит времени в минутах. Без него тест без таймера. Лимит **не блокирует**: ученик может закончить и позже, а вы увидите пометку «не уложился» |
| `questions` | да | Список вопросов, минимум один |

Регистр в `topic` и `section` не важен: `генетика` и `Генетика` — одно и то же.
Если тема или отдел не найдены, загрузка не пройдёт и покажет, какое значение не распознано —
молча подставлять «не указано» платформа не будет.

## Вопрос с одним верным ответом

```json
{
  "text": "На какой фазе митоза хромосомы располагаются по экватору клетки?",
  "type": "single_choice",
  "options": ["Профаза", "Метафаза", "Анафаза", "Телофаза"],
  "correct": 2,
  "explanation": "В метафазе хромосомы выстраиваются в экваториальной плоскости."
}
```

- `options` — минимум 2 варианта, просто список строк.
- `correct` — **номер верного варианта, считая с 1**. В примере верный ответ — «Метафаза».
- `explanation` — необязательно; показывается ученику в работе над ошибками.

## Развёрнутый вопрос

```json
{
  "text": "Опишите взаимодействие популяций «хищник — жертва».",
  "type": "open",
  "points": 2,
  "answer": "Численность хищника следует за численностью жертвы с запаздыванием",
  "explanation": "Проверяется вручную."
}
```

- `answer` — эталонный ответ, который вы увидите при проверке. Необязателен.
- `points` — **максимум баллов** за вопрос, 1–10 (по умолчанию 1). Ставьте 2–3, как во
  второй части ЕГЭ: при проверке вы сможете дать частичный балл, и он корректно попадёт
  в прогресс ученика (1 из 2 — это 50%, а не «неверно»).
- Такие вопросы проверяет репетитор: после сдачи попытка попадает в очередь проверки,
  а ученик сразу видит балл за автопроверяемую часть с пометкой «на проверке».

`points` можно указать и у вопроса с выбором, если он «стоит» больше одного балла —
там он начисляется целиком либо не начисляется вовсе.

## Частые ошибки

| Сообщение | В чём дело |
|---|---|
| `Файл не является корректным JSON` | В файл попал текст вокруг блока — например, «Вот ваш тест:». Оставьте только сам JSON |
| `Вопрос 3 (correct): correct = 5, а вариантов всего 4` | Номер верного ответа больше числа вариантов |
| `Вопрос 7: нужно минимум 2 варианта ответа` | У вопроса с одним верным ответом меньше двух вариантов |
| `Тема «Ботаника» не найдена` | Такой темы нет в справочнике — проверьте название или код в разделе «Темы» |
| `Поле «topic»: тема у теста обязательна` | Не заполнена тема. У материалов она необязательна, у тестов — обязательна |

Нумерация вопросов в сообщениях совпадает с их порядком в файле.
